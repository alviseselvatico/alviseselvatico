# Architectural / Product Decisions

Keep this file short. Add a dated entry when a material decision changes.

## 2026-09-09 — D001 — Modular monolith first
Decision: build a local Python modular monolith before distributed services.
Reason: fastest path to test the ranking/editorial hypothesis.

## 2026-09-09 — D002 — Rights gate is a domain primitive
Decision: source rights policy is mandatory and defaults to block.
Reason: rights cannot be bolted on after automated ingestion/publishing.

## 2026-09-09 — D003 — Human-in-the-loop publishing
Decision: no autonomous public publication in early phases.
Reason: rights, factual accuracy, quality and channel risk.

## 2026-09-09 — D004 — FFmpeg as deterministic rendering core
Decision: use FFmpeg/ffprobe for the base renderer.
Reason: reproducibility, cost, portability and control.

## 2026-09-09 — D005 — Provider abstraction
Decision: transcription, LLM, evidence retrieval and publishing use adapters.
Reason: pricing and model capabilities change rapidly.

## 2026-09-09 — D006 — Data before ML
Decision: begin with heuristics + structured LLM features; collect labels before training bespoke models.
Reason: custom ML without quality labels is premature.

## 2026-09-09 — D007 — English-first content experiment
Decision: initial owned media experiment is designed for English-language verticals.
Reason: larger reachable audience and broader monetization/distribution options; not a limitation of core software.

## 2026-09-09 — D008 — Claude Code builds the system, not necessarily every production inference
Decision: Claude Code is the primary development agent. Production routing may use cheaper/specialized models.
Reason: reduce operating cost and avoid architecture coupling.

## 2026-09-09 — D009 — Rights policy invariants live in the domain model
Decision: `basis_type` governs the capability flags. `BLOCKED` and `UNKNOWN` force every `can_*` flag to false; `TRANSFORMATIVE_REVIEW_REQUIRED` forces `can_publish=false` and `review_required=true`. The invariant is enforced by the `RightsPolicy` model validator and covered by tests; the gate then checks flags only.
Reason: two sources of truth (basis type vs flags) would let a mis-entered record pass the gate.

## 2026-09-09 — D010 — Phase 0 fact check is human-only
Decision: in Phase 0 every claim generated by VME is created `UNVERIFIED` and blocks the draft (`blocked_factcheck`) until an operator marks it `HUMAN_APPROVED` or `REMOVED`. No evidence-retrieval adapter until Phase 1.
Reason: proves the gate mechanics without building retrieval before the ranking hypothesis is tested.

## 2026-09-09 — D011 — Transcription: local faster-whisper first
Decision: the first transcription adapter is `faster-whisper` (local, CPU/GPU), word-level timestamps, no diarization in Phase 0. Provider and model size come from configuration. A hosted STT adapter (with diarization) is a Phase 1 option behind the same interface.
Reason: zero API cost, no key, reproducible outputs, adequate for English long-form; diarization is not needed for the Phase 0 exit criteria.

## 2026-09-09 — D012 — LLM routing: two tiers via aliases
Decision: the LLM adapter exposes two aliases, `cheap` and `strong`, resolved from environment configuration (`VME_LLM_PROVIDER`, `VME_LLM_MODEL_CHEAP`, `VME_LLM_MODEL_STRONG`). First provider implementation: Anthropic Messages API with structured JSON output validated by Pydantic. No model ID in code.
Reason: matches the cost funnel; keeps D008 (Claude Code builds, production may route elsewhere).

## 2026-09-09 — D013 — Phase 0 reframe: blurred-background letterbox
Decision: 16:9 sources are rendered at 1080x1920 as a centered source layer over a blurred, scaled copy of itself. No speaker tracking, no face detection, no smart crop in Phase 0.
Reason: deterministic, one FFmpeg filter graph, no ML dependency; smart reframing is a measured Phase 2+ improvement.

## 2026-09-09 — D014 — Phase 0 commentary is text-only
Decision: original editorial value in Phase 0 is delivered as hook card + burned-in captions + optional text overlays. No TTS narration, no synthetic voice, no generated video.
Reason: avoids a TTS adapter, a voice choice and synthetic-media disclosure obligations before the pipeline is validated.

## 2026-09-09 — D015 — Tooling
Decision: `uv` for environment and lockfile, `ruff` (lint + format), `mypy --strict` on `src/`, `pytest`. Python 3.12+. Single `pyproject.toml`.
Reason: one fast, reproducible toolchain; avoids ad-hoc choices across sessions.

## 2026-09-09 — D016 — Test fixtures
Decision: audio/video fixtures for probe/render tests are generated at test time with `ffmpeg -f lavfi` (never committed). One short operator-owned speech clip (<= 90 s, WAV, `OWNED` policy) is committed under `fixtures/speech/` via an explicit `.gitignore` allow rule, and is the only committed media in the repository.
Reason: `.gitignore` blocks media by default; transcription tests need real speech; everything else is reproducible.

## 2026-09-09 — D017 — Source supply is a Phase 1 entry condition
Decision: Phase 1 (golden set) cannot start until at least 3 distinct authorized sources (OWNED, EXPLICIT_LICENSE or CREATOR_AUTHORIZATION) totalling >= 3 hours of English speech are registered with evidence. The operator maintains the list in `docs/SOURCES.md`.
Reason: 50-100 labeled candidates cannot come from one file; authorized supply is the real bottleneck, not code.

## 2026-09-09 — D018 — Phase 0 media registration references the operator's file in place
Decision: `media register` stores the resolved absolute path of the local file plus its SHA-256; it does not copy the file into `artifacts/source/`. Logs show only the file name unless the path is inside the artifacts directory. A permissive `basis_type` additionally requires a non-empty `basis_reference` at the model level (SOURCES.md rule: no evidence = `UNKNOWN`).
Reason: Phase 0 works on one local authorized file; duplicating gigabytes buys nothing, and the fingerprint detects a changed or moved file at the next step. Copying/object keys arrive with object storage (ARCHITECTURE §9).
